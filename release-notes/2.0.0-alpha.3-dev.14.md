# 2.0.0 Alpha 3 Dev 14

## Purpose

Dev.14 is the corrective test build after the Dev.13 Mustang live-verification findings. It keeps the verified Thermal, Bootguard, ZRAM 100p, `lz77eh`, swappiness and post-OTA state-refresh work, while making Emerald Hill adaptive operation the safe daily default.

## Emerald Hill safety

- Deduplicates physical devfreq devices across `/sys/class` and `/sys/devices/platform` aliases.
- Keeps the preferred class path while recording one authoritative baseline per physical node.
- Restores legacy Dev.13 duplicate baselines once per physical device, preserving the first true original minimum.
- Adds status schema v2 with path, original minimum, observed maximum, target, alias count and one-shot post-Bootguard mode.
- Migrates legacy or inconsistent lock choices to adaptive operation.
- Keeps the optional maximum-frequency minimum lock behind a dedicated explicit acknowledgement.
- Describes the lock accurately: it does not exceed the kernel maximum, but can increase power and heat by preventing downclocking.

## ZRAM and LMK policy

- Keeps ZRAM 100 percent, `lz77eh` and `vm.swappiness=100`.
- Removes the unverified late `ro.lmk.swap_free_low_percentage=1` override.
- Records `lmk_swap_low_policy=stock_unmodified`.
- Keeps ZRAM enhancement operation independent from the optional EH lock.

## Installer and observability

- Fresh choices now start at Stock Polling, Stock Thermal, ZRAM disabled, EH disabled, pTune override off and silent logging.
- Use-last behavior remains available separately.
- pTune, ZRAM and EH risk acknowledgements are recorded in distinct fields.
- Action and installer labels use Adaptive and Maximum lock terminology instead of calling the kernel-exposed maximum an overclock.

## Verification boundary

Repository CI and deterministic packaging are required before producing a device test ZIP. This development build is not a public release and does not change stable or prerelease update channels. A fresh install, reboot and Mustang runtime verification remain mandatory before any release decision.
