# 2.0.0 Alpha 3 Dev 15

Private corrective test build; no tag, public release asset, or update-channel change.

## Install defaults

Fresh installation now keeps the intended daily defaults selected:

- Polling Mod;
- ZRAM 100 percent with adaptive Emerald Hill;
- verbose logging;
- Stock Thermal;
- pTune override off.

Use-last remains separate and preserves the previously saved choices.

## Menu and helper wiring

- Adds a complete installer and Action route matrix covering all visible menu branches, Back and timeout behavior.
- Makes Action ZRAM enable/disable transactional: the fstab layout is materialized or removed before configuration is committed.
- Marks all Action ZRAM layout changes as reboot-required.
- Makes standalone ZRAM enable/disable helpers use the same materializer and current EH risk fields.
- Preserves unrelated configuration when disabling the pTune override.
- Removes the obsolete LMK override and old EH state name from the manual ZRAM reinit path.
- Updates fallback ZRAM menu behavior and stale Emerald Hill wording.

Fresh device installation and post-reboot verification remain mandatory before any release decision.
