# 2.0.0 Alpha 3 Dev 17

Private corrective test build; no tag, public release asset, or update-channel change.

## Live verification input

Dev.16 booted with healthy Thermal, ZRAM 100 percent, lz77eh, adaptive Emerald Hill and stock LMK behavior. The selected Outdoor Extended profile was intentional and valid. The remaining verification failures came from `auto-profile-switch.sh` replacing the complete install-time `install-state.txt` with a shorter runtime-only document.

## Corrections

- Preserves install-time evidence while merging current runtime state after boot.
- Keeps explicitly selected Thermal profiles such as Outdoor Extended instead of treating Stock as a mandatory result.
- Separates canonical install evidence from runtime validation through `profile_state` and `runtime_profile_state` fields.
- Preserves pTune, ZRAM, Emerald Hill and debug observability across boot-time state refreshes.
- Makes a second unchanged boot idempotent instead of rewriting the state file again.
- Adds regression coverage for manual Outdoor Extended selection and complete state preservation.

Fresh Mustang installation and post-reboot verification remain mandatory before any release decision.
