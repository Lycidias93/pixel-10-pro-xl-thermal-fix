## Main changes

- Unknown supported-platform builds are admitted through local stock-derived validation instead of an exact-build activation list.
- Magisk Action no longer waits for a GitHub API or raw-file refresh.
- Polling, Thermal, ZRAM, pTune override, and Debug choices are collected once in a single install-menu process.
- Thermal and ZRAM installers are noninteractive materializers after confirmation.
- Persistent validation evidence is canonical under `/data/adb/pixel-10-pro-xl-thermal-fix/validation/`.
- Historical validation paths are compatibility symlinks instead of independent report copies.
- Release packages exclude repository-only directories, tests, documentation, release notes, Git metadata, and release-policy helpers.
- Action startup and rematerialization timing are recorded locally.
- Installer evidence now records package hash and size, battery/power state, and elapsed installation time when available.

## Dynamic-build evidence boundary

The code and CI cover `dynamic_unverified` local admission for an unlisted supported Pixel 10 / Android 17 build. This prerelease does **not yet** have an external unlisted-build install and postboot proof. Testers on Canary or newly released monthly builds should retain a working module-disable or recovery path and submit the install autosave plus postboot compatibility output.

This limitation does not change the fail-closed platform boundary: unsupported device codenames, unsupported Android major versions, missing stock files, malformed stock structures, unexpected patch differences, or failed validation keep Thermal disabled while ZRAM may remain available.

## Safety and rollback

- pTune coexistence remains experimental. Installed-disabled is safe; active pTune requires explicit acknowledgement.
- ZRAM 100p remains optional and requires explicit selection.
- To roll back, disable or remove the module in Magisk and reboot.
- This prerelease does not disable Android Thermal safety, replace the stock Thermal HAL, overclock the device, or provide a benchmark/FPS unlock.
