# 2.0.0-alpha.3-dev.21 (test source)

Dev.21 is an unreleased device-test build.

## LMKD property writer

- Keep `resetprop-rs` for normal ZRAM properties.
- Set `ro.lmk.swap_free_low_percentage=1` with Magisk's system `resetprop` first.
- Verify the property readback.
- Fall back to `resetprop-rs` only when the system writer is unavailable or its readback is not `1`.
- Record `property_writer=magisk_resetprop|resetprop_rs_fallback` in LMKD Reload Evidence.

## Lightweight normal boots

Full Dynamic V2 compatibility verification now runs only when needed: first install, module update, firmware/build change, configuration or overlay change, pending platform transition, previous pending boot, debug/canary mode, or missing/invalid last-good evidence.

An unchanged verified boot skips the full compatibility scan. It only loads the selected state, applies ZRAM/LMKD/EH, performs lightweight live readbacks, refreshes the P/T/Z/L badges, and exits. Bootguard still escalates automatically whenever the signed state changes.

## Required device checks

1. Dirty-flash Dev.21 and reboot.
2. Verify the first Dev.21 boot reports `boot_verification_mode=full`.
3. Reboot again without changing settings and verify `boot_verification_mode=fast`.
4. Confirm badges return automatically without opening Action.
5. Confirm LMKD Reload Evidence reports property `1`, a successful reload, and the property writer used.
6. Remove the module in Magisk, reboot, and verify both `/data/adb/modules/pixel-10-pro-xl-thermal-fix` and `/data/adb/pixel-10-pro-xl-thermal-fix` are absent.
