# 2.0.0 Alpha 3 Dev 8

## Purpose

Dev.8 removes the obsolete exact device/build allowlist that blocked Outdoor profiles on otherwise supported Pixel 10 devices such as Blazer.

## Admission model

- Supported Pixel 10 family devices on Android 17 may request Stock, Outdoor Safe, Outdoor Plus, or Outdoor Extended.
- Exact build IDs remain evidence labels only; they no longer activate or block profiles.
- Every non-stock request still passes through the local stock-derived Fix 5 materializer and independent validator.
- Unsupported devices or Android versions remain Stock-only.

## Evidence retained

- Mustang stable `CP2A.260705.006`: Dev.6 Outdoor Extended postboot PASS, 12 zones / 12 arrays / 84 values.
- Mustang Canary `ZP11.260618.005`: Allen Fix 5 clean-flash profile matrix PASS.
- Blazer stable `CP2A.260705.006`: Harish Fix 5 Outdoor Extended PASS, 13 zones / 13 arrays / 91 values.

## Safety

The change removes only the redundant activation gate. Structural validation, diff validation, transactional Action changes, Bootguard, pTune policy, and rollback behavior remain in place.

This public prerelease supersedes Dev.6 on the prerelease update channel. The stable release and stable update channel remain unchanged.
