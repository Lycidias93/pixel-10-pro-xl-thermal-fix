# 2.0.1

2.0.1 is a focused Dynamic V2 hotfix for newer Pixel 10 Thermal files.

## Fix

- Accepts both compact and multiline `HotThreshold` arrays during independent Outdoor-delta validation.
- Keeps exact per-value delta checks, target-zone matching, sentinel preservation, controlled-file scope, and fail-closed behavior unchanged.
- Fixes the false `rc=63` install rejection seen after the August Thermal file formatting change.

## Device verification

The hotfix code was verified on Pixel 10 Pro XL (`mustang`) running Android 17:

- August Stable `CP2A.260805.005` on KernelSU: install passed, full post-reboot Bootguard/runtime verification passed, all three active `/vendor/etc` Thermal files matched their validated overlays, Polling Mod was active at `22/22` values of `5000` with no remaining controlled `300000` values, and ZRAM 100% was active.
- August Canary on `mustang`: independently verified by Allen Chang.
- July Stable `CP2A.260705.006` on Magisk: regression install validation remained green with all `22/22` Polling replacements and all 12 target zones / 84 threshold values validated.

Thanks to **mOjO jOjO** and **Allen Chang** for the fast August validation.

## Scope

This release does not add Pixel 10a support. `stallion` / Tensor G4 support remains a separate device-family validation task.
