# Pixel Thermal & Memory Control 2.1.0-alpha.7

This is a **public vNext prerelease**. Stable users can remain on 2.0.4; Alpha7 advances the Pixel 11 integration and update path after the Alpha6 baseline.

## New in 2.1.0-alpha.7

- **Pixel 11 recovery controls are integrated into the normal vNext line.** HotHysteresis and MaxReleaseStep are independent controls; enabling both uses the combined internal recovery state without exposing a redundant third Combined option.
- **Stock Pixel 11 Thermal mode no longer mounts generated Thermal JSON overlays.** A ZRAM-only setup can keep its ZRAM fstab override while the device continues using stock Thermal files.
- **Pixel 11 polling and PassiveDelay remain stock-only.** The earlier faster PassiveDelay experiment is not part of this prerelease.
- **Outdoor Safe remains limited to +1 °C on the exact admitted VIRTUAL-SKIN target.** CPU/SOC derivatives, radio/modem, charging and protection objects stay outside that change.
- **Prerelease updates now advance to the distinct Alpha7 package.** This prevents an integrated Pixel 11 test/install from resolving back to the older Alpha6 package through the normal module-manager update path.
- **The Alpha6 WebUI safety fixes are retained,** including Android-safe non-mutating previews/dry-runs, the HUP-safe standalone WebUI lifetime and the pinned shared WebUI Core 0.6.6 behavior.

## Compatibility and safety

- Pixel 9/9a/10/10a behavior stays on the existing vNext path.
- Pixel 11 classic PollingDelay and PassiveDelay controls are not exposed.
- pTune Thermal coexistence override remains blocked on experimental Pixel 11 targets.
- ZRAM, Emerald Hill and page-cluster experiments remain separately controlled and reversible where supported.
- The WebUI remains loopback-only and uses the same guarded typed control surface for standalone and embedded launch paths.

## Updating

Users on the prerelease channel can update through the normal module-manager flow after the Alpha7 channel metadata is promoted. Reboot after flashing before judging runtime state.
